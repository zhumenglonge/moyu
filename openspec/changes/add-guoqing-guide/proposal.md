# Proposal

## Why

用户和几位朋友正在规划国庆出行，需要一个能直接发到群里、让朋友们横向对比后拍板的攻略。口头推荐无法承载"怎么去 / 花几天 / 挤不挤 / 有什么坑"这类决策信息，而摸鱼大厅已有「长沙去哪玩」证明"页面 + 一键复制发群"是顺手的分享形态。

## What Changes

- 新增 `games/guoqing/` 栏目（index.html + guoqing.js 文件对），是一个**静态攻略页**而非随机生成器。
- 页面收录八条经过探索/追加确认的主线，分两档展示（用户追加确认）："高铁 3h 圈"边界保持不变，A~D 为**核心档**（省内、真决策用）；E~H 为**遐想档**（跨省/飞机方向，不一定真去，给群友留心动和讨论的空间）：
  - A 南岳衡山（衡阳）· 文化线 · 3 天 2 晚
  - B 莽山 + 东江湖（郴州宜章/资兴）· 湖景云海线 · 3 天 2 晚（不泡温泉）
  - C 邵阳崀山（新宁）· 风景线 · 4 天 3 晚（可压缩为 3 天）
  - D 娄底湄江（+紫鹊界可选加段）· 避世线 · 3 天 2 晚
  - E 桂林（阳朔 + 龙脊）· 山水田园线 · 4 天 3 晚 · 遐想档（国庆正值龙脊稻谷金黄季）
  - F 云南（昆明 + 建水 + 东川红土地）· 高原古城线 · 4 天 3 晚 · 遐想档（飞机方向，避开大理丽江人流陷阱）
  - G 贵州（西江千户苗寨 + 镇远）· 苗侗文化线 · 3 天 2 晚 · 遐想档（凯里高铁约 2~2.5h，虽在圈内但按跨省方向归档）
  - H 重庆（山城城区）· 山城美食线 · 3 天 2 晚 · 遐想档（飞机约 1.5h，纯城区零赶路）
- 每条路线渲染为统一字段的情报卡：怎么去 / 花几天 / 花费 / 拥挤度（星级）/ 每日安排 / 坑 / 吃什么。
- 页面顶部新增"距离国庆还有 N 天"倒计时彩蛋；国庆当天及之后自动切换为"距下次国庆 N 天"的摸鱼自嘲文案。
- 每条情报卡带"📋 复制这条路线发群"按钮，复制纯文本版行程（沿用 changsha 的剪贴板模式与降级提示）。
- 按项目扩展点规范同步三处：大厅 `index.html` 加卡片、`css/style.css` 末尾追加样式、`README.md` 补功能表格与目录树。
- 明确不做（Non-goals）：投票/点赞功能（无共享存储层，探索阶段已裁决砍掉）、随机摇路线生成器、张家界等国庆人流陷阱路线（正文不收录）。

## Capabilities

### New Capabilities
- `guoqing-guide`: 国庆攻略栏目——八条长沙出发路线情报卡的展示、国庆倒计时彩蛋、单路线一键复制发群的对外行为。

### Modified Capabilities

（无——项目尚无既有 specs，本变更不修改任何已有能力的需求。）

## Impact

- 新增文件：`games/guoqing/index.html`、`games/guoqing/guoqing.js`。
- 修改文件：`index.html`（大厅卡片）、`css/style.css`（末尾追加）、`README.md`（表格 + 目录树）。
- 复用：`js/common.js`（老板键、localStorage 工具、剪贴板模式参照 changsha.js）。
- 无新增依赖、无后端、无构建变更；机票/高铁时刻等外部信息仅作为文案内容，不引入任何外部 API；部署仍为推送 main 自动发布 GitHub Pages。
